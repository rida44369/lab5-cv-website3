# Rida Fatima — Personal Portfolio Website

## 1. Project Overview
This project is a personal portfolio website developed for Rida Fatima. It presents her introduction, education, technical skills, courses, projects, and contact information in a professional layout.

## 2. Objectives
- To create a professional online portfolio.
- To showcase educational background and technical skills.
- To display projects and completed courses.
- To provide contact information through a dedicated contact page.
- To create a responsive and user-friendly website.

## 3. Technologies Used
- **HTML5:** To structure the website.
- **CSS3:** To design the layout, cards, colors, animations, and responsive interface.
- **JavaScript:** To add interactivity, form validation, and visual effects.
- **Font Awesome:** To display icons.

## 4. Website Pages

### Home Page
Introduces Rida Fatima and highlights important information about her portfolio.

### About Page
Displays her personal introduction, career objective, educational background, and personal qualities.

### Skills Page
Shows technical skills, soft skills, courses, and project details.

### Contact Page
Displays contact information and a form for visitors to enter their messages.

## 5. Main Features
- Professional navy blue and gold color theme.
- Responsive layout for different screen sizes.
- Individual cards for different information sections.
- Navigation menu to move between pages.
- Hover effects and scrolling animations.
- Contact form input validation.
- Font Awesome icons.
- Profile picture display.

## 7. How to Run the Website
1. Open the project folder in Visual Studio Code.
2. Make sure all HTML, CSS, JavaScript, and image files are present.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.
